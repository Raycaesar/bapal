What is (Epistemic) Logic?

Epistemic Logic is way of formally reasoning about knowledge. In order to understand how Epistemic logic works, let's start with classical logic and build up from there.

Classical Logic and Formulas

In classical logic we start with propositional variables, our propositional variables are $p$, $q$, $r$, $s$, and $t$. Each propositional variable can either be true or false. For example we can say $p$ is false, written as $\lnot p$, and let's say $q$ is true, written just as $q$.

Alongside propositional variables, we have the classical logical connectives:

  • $\lnot A$ (not) which is true when $A$ is false,
  • $A \land B$ (and) which is true when both $A$ and $B$ are true,
  • $A \lor B$ (or) which is true when $A$ is true, or $B$ is true, or both are true,
  • and $A \rightarrow B$ (conditional) which is true if $B$ is true whenever $A$ is true.

We can apply the logical connectives, along with parantheses, to propositional variables to build up complex formulas. For example $(p \rightarrow q) \land (q \rightarrow p)$ is a formula which is true when $p = q$, or $p \lor \lnot p$ is a formula which is always true!

pro tip: $(p \rightarrow q) \land (q \rightarrow p)$ can be written shorthand as (p <-> q) in the playground.

Worlds, Agents, and Epistemic Logic

Epistemic Logic is designed for reasoning about the knowledge of someone (we call that someone an agent). We might imagine that an agent does not know whether they are in a situation where $p$ is true, or a situation where $p$ is not true, i.e. $\lnot p$. We express situations as worlds. We express an agent's knowledge by drawing relations (arrows) between worlds. These worlds and agent relations together are called a model.

When you enter a classical formula into the playground, the formula is evaluated at each world as if that world was just a classical logic by itself. Epistemic logic introduces a new logical connective which takes advantage of agents' relations between worlds:

  • $K_b A$ (knowledge of an agent $b$) which is true at a world when $A$ is true at all worlds connected to that world by $b$ arrows.
  • along with $K_{a,b,c} A$ which is shorthand for $K_a A\land K_b A\land K_c A$.

Now, I understand if this definition isn't intuitive, it's not obvious what $K_b A$ has to do with knowledge. In order to start intuitively understanding, let's consider our previous example. We can write a formula to check whether an agent $a$ knows that they are in a situation where $p$ or that they know they are in a situation where $\lnot p$:

$K_a p \lor K_a \lnot p$.

This formula is false, by definition of $K_a$, at both worlds because they are each connected to both a world where $p$ is false and a world where $p$ is true.

In an intuitive sense, agent $a$ does not know what $p$ is because they cannot distinguish between the world where $p$ is true and the world where $p$ is false.

If you add more than one agent you can reason about one agent's knowledge of another agent's knowledge e.g. $K_a K_b p$, $a$ knows that $b$ knows that $p$ is true.

Finally, for the sake of representing knowledge, in Epistemic logic it is expected that all agent's relations between worlds are equivalence relations, i.e. each agent's relation is:

  • reflexive, so each world is related to itself;
  • symmetric, if a world $0$ is related to a world $1$, then world $1$ is also related to world $0$;
  • and transitive, if a world $0$ is related to a world $1$, and world $1$ is related to world $2$ then world $0$ has to be related to world $2$ as well.

Dynamic Epistemic Logic - Public Announcement

Dynamic Epistemic Logic introduces announcement, a mechanism for publicly announcing facts that become the knowledge of all agents. Given a formula $A$, a public announcement removes all worlds where $A$ is not true.

Dynamic Epistemic Logic also introduces a logical connective:

  • $[A]B$ (public announcement of $A$) which is true at a world if $B$ is true after $A$ is announced, or if the world is removed by the announcement.

Try out the announcement button and the announcement connective in the playground.

Boolean Arbitrary Public Announcement Logic (BAPAL)

Public Announcement Logic (PAL) has formulas of the form [A]B, meaning: after publicly announcing A, formula B holds. Arbitrary Public Announcement Logic (APAL) adds quantification over possible public announcements. Its existential announcement operator says, roughly, that there is some true announcement which, after being publicly announced, makes the target formula true.

Boolean Arbitrary Public Announcement Logic (BAPAL) restricts those arbitrary announcements to Boolean, or propositional, formulas. A Boolean announcement is built only from propositional atoms and Boolean connectives such as negation, conjunction, disjunction, implication, and equivalence. It does not contain knowledge operators like K{a}, public announcement operators like [A]B, or the BAPAL operator ^A.

Because Boolean announcements depend only on propositional valuations, they cannot separate two worlds that assign the same truth values to all propositional atoms. In finite models, quantifying over Boolean announcements can therefore be implemented by quantifying over unions of propositional valuation classes.

This app uses ^A as the ASCII input syntax for the existential Boolean-announcement diamond ◇ᵝA. The superscript β marks Boolean announcement and is not an agent. It means: there exists a Boolean announcement α, true at the current world, such that after publicly announcing α, A is true. This is an implementation of the existential Boolean-announcement operator, not ordinary exponentiation and not a TeX superscript. Informally, ^K{a}p corresponds to the logical reading ◇ᵝKap.

S5 Mode

BAPAL is normally interpreted on epistemic models where each agent's accessibility relation is an equivalence relation. S5 mode is a model-construction aid for building such relations.

When S5 mode is off, the playground behaves like the old graph editor: you manually draw directed arrows and can adjust their directions. When S5 mode is on, you do not need to add a forward arrow, a backward arrow, and self-loops one by one. Dragging a relation between two worlds for the current agent automatically treats them as belonging to the same equivalence class, and the app stores the required reflexive, symmetric, and transitive relations in the underlying model.

In S5 mode, selected-transition Delete, L, R, and B are ignored so they cannot silently turn an equivalence relation into a one-way or partially deleted relation. Switch S5 mode off if you want ordinary individual-arrow editing. Deleting a selected world is still allowed; the remaining stored relations keep their S5 properties.

Reflexive self-loops are assumed and stored in S5 mode, but they are hidden in the graph by default to avoid visual clutter. To introduce a new agent, for example if agent a is already present and you want to add agent b with only reflexive S5 relations and no non-trivial edges, select agent b, select a world, and press R. In S5 mode, this adds the reflexive b relation needed for that agent. The graph may not show loops, but the model stores them.

The Reflexive / Symmetric / Transitive checkboxes report properties of the stored model, not merely the visible graph.

Syntax

  • use ~A for negation
  • use (A & B) for conjunction
  • use (A | B) for disjunction
  • use (A -> B) for implication
  • use (A <-> B) for equivalence
  • use K{a}A for agent a knows A
  • use K{abc}A as shorthand for each listed agent knowing A
  • use [A]B for public announcement
  • use ^A for the existential Boolean-announcement diamond ◇ᵝA

Examples

  • ^K{a}p: there is a Boolean announcement after which agent a knows p.
  • ^~K{a}p: there is a Boolean announcement after which agent a does not know p.
  • ^K{a}~K{b}p: there is a Boolean announcement after which agent a knows that agent b does not know p.

Further reading: Hans van Ditmarsch and Tim French, "Quantifying over Boolean Announcements", Logical Methods in Computer Science, 2022. The paper studies BAPAL as a restriction of APAL where quantification is over Boolean announcements.
